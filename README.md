# Shift — Interactive Product Prototype (Desktop & Android)

> **Zero chat. Pure execution.**

Interactive React + TypeScript + Tailwind + Framer Motion + GSAP prototype for **Shift** (v2.4), showcasing synchronized Desktop (`1200×760`) and Android (`390×844`) workspaces:

- **4-Step Stateful Onboarding** (Philosophy, Pipeline Connections, Autonomy & Focus Window, Live Calibration)
- **Priorities / Today’s Triage** with live execution sweeps, undoable Sonner-style toasts, and autonomous Background Activity log
- **Inbox** with distilled briefs, staged actions, promote-to-priorities, archive, and noise sweep
- **Calendar** with horizontal Week/Month strip on Desktop, tactile Month/Week grid on Android, expandable agenda blocks, conflict decline, slot optimization, and focus shields
- **Automations** with live IF/THEN toggles, test runs, and custom rule creation
- **Focus Mode** with live countdown timer, progress hairline, and linked context pinning
- **Command Bar (`⌘K` / `Ctrl+K`)** on Desktop & **Quick Command Bottom Sheet** on Android

## Run Locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
